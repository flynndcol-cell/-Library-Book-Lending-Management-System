# -Library-Book-Lending-Management-System
一個初具雛形的 圖書館 必備軟件，有問題 or BUG 可以反饋讓我們知道。 **本軟件使用python開發

## 繁體中文說明

### 🌟 主要功能特色
1. **書籍與庫存管理**：
   - 支援 ISBN 條碼記錄、書名、作者、分類、總數量與可借數量追蹤。
   - 即時關鍵字搜尋（支援書名、作者、ISBN 與編號模糊搜尋）。
   - 書籍封面圖片路徑綁定與狀態顯示。
2. **會員與黑名單管理**：
   - 會員基本資料管理（編號、姓名、電話）。
   - 帳號停權（黑名單）機制與未繳罰款追蹤控管。
3. **借還書與逾期管理**：
   - 支援條碼槍模擬 / 手動快速輸入。
   - 自訂借閱天數與每日逾期罰款金額計算。
   - 自動計算逾期天數與罰款並記錄於會員帳上。
4. **借閱歷史與報表**：
   - 完整的歷史借閱軌跡查詢（包含借書日、到期日、實際還書日與罰款繳納狀態）。
5. **營運數據即時儀表板**：
   - 直觀顯示館藏總冊數、外借中數量、架上可借閱數、註冊會員數、進行中借閱單與累計罰款總額。
